Privacy,
without fine print.

Agent Secret Capsule is local-first. The CLI has no telemetry, analytics, account, or hosted secret store. Credential values are written only to your operating-system keychain and injected into the subprocess you explicitly select.

Local CLI data

The CLI stores secret aliases and no-value receipts in your user data directory. Receipts contain the time, alias, environment variable name, executable name, duration, outcome, exit code, lease length, and redaction count. They never intentionally contain the credential value or full command arguments. You control and may delete these files.

Website and licenses

This site does not use analytics, advertising cookies, or third-party scripts. If you paste or return with a license token, the token and a cached verification result are stored in your browser’s localStorage. The token is sent only to Sociobot’s license verification API. You can remove it by clearing site data.

Purchases

Sociobot/Dodo is the merchant of record and processes checkout data under its own notices. This site does not receive or store card details. The license service returns only whether a token is valid and its status.

Network warning

The command you authorize may make network requests. Agent Secret Capsule cannot prevent that command from sending the credential or derived data to its configured endpoint. Review the command and use a separate sandbox when appropriate.

Contact

For privacy requests or questions, open an issue in the project’s public source repository without including any secret or license token.
