HOW THE CREDENTIAL TIME LIMIT WORKS

Select. Run. Redact.
Review the receipt.

Use a local alias in the agent tool input.

  1. 01
    Select

    Store an alias locally. Use the alias in the agent tool input.

  2. 02
    Run

    The selected process and its children receive the credential until exit or the time limit.

  3. 03
    Redact

    ASC captures both output streams and replaces matching credential forms before printing them.

  4. 04
    Review receipt

    A no-value receipt omits the credential.

INSTALL / v0.1.0

Build the CLI. Run the sample.

Use the bundled demo before storing a real credential.

cargo install --path crates/asc && asc demo

STORE / STDIN INPUT

printf '%s' "$TOKEN" |
asc put cloudflare --stdin

RUN / 30-SECOND LIMIT

asc run cloudflare --env
TOKEN --ttl 30s -- curl …

RECEIPTS / JSON

asc receipts --json

SECURITY LIMITS

Redaction limits output leaks.
It is not a sandbox.

An authorized command can send the credential over the network or write it to a file. It can also transform it or pass it to a child.

Review the command and endpoint. Use a separate network and process sandbox for hostile code.
