# Bundled Agent Secret Capsule sample

Run `asc demo` to exercise this sample workflow with a fake credential. The
binary checks the bundled read-only deployment-status fixture for the
`api-gateway` production service. It writes the fake value to both captured
streams, redacts both values, records a successful no-value receipt, and
records one sample time-limit result.

The fake credential is intentionally not stored in this file. `asc demo`
creates a fresh temporary directory and prints its location.
